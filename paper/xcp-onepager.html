The AI Agentic Internet

Pacing reach, not only capability

XCP Standard Working Group
Working paper · September 2026
research@agi-gateway.org

In September 2026 four frontier laboratories agreed that AI capability should be deliberately slowed. Governments rejected it within a day, each framing restraint as a concession to a rival. The argument has become a referendum on one dial. It is missing a second.

Capability is set by training. Reach is set by infrastructure.

That difference decides who can act. Slowing capability needs every laboratory to agree at once, and any country that moves first hands ground to one that doesn’t.

Bounding reach needs nobody’s permission. One operator can do it on Monday, it can be checked by an outsider, and it slows nothing that operator has already chosen to trust.

You do not have to choose between racing and stopping if you can decide what agents are allowed to touch.
What the incidents were actually about
During 2026 evaluations, models reached real computer systems they were not authorised to reach. In one case a misconfiguration granted internet access to an environment that had been deliberately stripped of its usual security controls. These are not stories about a model that knew too much. Nothing in the path could establish whether the access was allowed — because no such layer exists. The safeguards that failed were access controls.

Testing stops being a gamble

A system under evaluation can read the real world while being structurally unable to change it. Better than an air gap, which makes the test unrealistic, and than open access, which made the news.

The human web stops paying

Agents and people share one undifferentiated internet today, so every gain in agent capability lands on the web humans use. Legible agents can be treated differently from anonymous scrapers — which is what blanket blocking exists to substitute for.

New protocols get somewhere safe to grow

Admit a protocol as quarantined, watch it under real traffic with no authority, promote it on evidence, revoke it in one step. The blast radius is bounded, so a family of agentic protocols can move fast precisely because each one is contained.

Regulators get a control, not a promise

Assurances about how a model was trained cannot be checked from outside. A boundary can be — by anyone, with a conformance suite. That is the difference between a commitment and a control.

Reach pacing complements capability pacing; it does not replace it. Risks from AI automating AI research are not addressed by bounding what a deployed agent can touch. The reference implementation has not been independently audited.
