# Maintainers

This project is maintained **anonymously**. There is no roster of names here by
design — see [GOVERNANCE.md](GOVERNANCE.md#anonymous-by-design) for what that
trades away.

Commit rights are held by the repository owners. Contributions are attributed to
"Anonymous Contributors" unless a contributor chooses otherwise.

Reach the maintainers through GitHub issues, or via private vulnerability
reporting for anything security-sensitive.
